This guide addresses **epson printer not printing black** with a focus on **printer alignment**. Start with observable symptoms, make one change at a time, and verify the outcome with a controlled test. The right steps depend on your printer model and how it connects.

## Understanding printer alignment

The key question in **printer alignment** is whether the symptom is reproducible on the printer itself or only through a particular computer or application. This distinction prevents unnecessary replacements and directs attention to the correct part of the printing workflow.

Before making changes, write down the current settings and the result of a simple test. A short record of what changed, when the issue began, and what worked makes the next diagnostic step more reliable and helps avoid repeating the same unsuccessful action.

## Step-by-step troubleshooting for printer alignment

### Step 1: Confirm the black ink symptom

Print a nozzle check directly from the printer and compare the black pattern with the other colors. A missing or broken black pattern suggests an ink-delivery or nozzle issue; a complete pattern suggests looking at document, driver, or print settings.

Printer menus vary across models and software versions. Use the names shown on your own device and refer to its model-specific documentation instead of assuming that a menu sequence from another printer applies unchanged.

### Step 2: Inspect ink and consumables

Check the physical tank level or cartridge status as appropriate for the model. Confirm the cartridge is seated and any installation seals have been removed as instructed. Do not touch electrical contacts or force components.

If a test produces a different result, use that difference as evidence. For example, a successful built-in test but an unsuccessful computer print usually points away from a complete mechanical failure and toward the connection, queue, application, or driver.

### Step 3: Use maintenance sparingly

If the nozzle pattern has gaps, run the standard head-cleaning function once and retest. Cleaning uses ink; repeated or power cleaning should follow the exact model manual and ink-level requirements.

Keep troubleshooting reversible where possible. Start with observation, status checks, and test prints; leave factory resets, firmware changes, invasive cleaning, and paid replacements until the evidence supports them.

### Step 4: Separate hardware from software

Try a printer-generated test page, then a simple black-text document. Compare Windows or macOS driver settings, paper type, grayscale options, and the selected printer. If the built-in test succeeds but app printing fails, focus on software.

For shared printers, ask whether other users experience the same behavior. One affected computer and several working computers suggest a client-side issue, while failures everywhere warrant checking the printer and shared network first.

### Step 5: Know when to stop

If black remains missing after model-approved troubleshooting, stop excessive cleaning and consult model-specific Epson support. Record the nozzle check and ink history before seeking service.

When reviewing help pages, match the full model identifier and operating system. Similar model names can have different supplies, maintenance procedures, and subscription policies.

## Frequently asked questions

### What should I check first for printer alignment?

Begin with the exact error or print result, then test the printer independently if possible.

### Should I reset the printer immediately?

Usually not. A reset can erase useful network and configuration information; try reversible checks first.

### How do I know whether the computer is responsible?

Compare a built-in printer test with the same job sent from another application or device.

### When should I contact support?

When safe model-specific checks fail, an error code persists, or hardware service appears necessary.

## Final checklist

For **printer alignment**, document the original symptom, printer model, connection type, tests performed, and the exact result of each step. A careful diagnosis is usually more useful than repeated resets or speculative purchases.
